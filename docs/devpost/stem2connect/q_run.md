**Try it in your browser.** Open [hound-command.vercel.app](https://hound-command.vercel.app) in Chrome on a laptop. It needs no install, no account and no payment. Press **Open the console**, then **Watch the demo** (about five minutes). The neural network runs live in the page. Press **Advanced** to open all 24 workspaces.

**Run the robot code.** You need Python 3.12 and NumPy. Clone [github.com/rishith-c/hound-ultra](https://github.com/rishith-c/hound-ultra) and run `python3 robot/sim/cases.py`, which reruns all 99 practice cases and writes the results table.

**What a good result looks like.** Every hidden person is confirmed or flagged, no room with someone in it is cleared, and no empty room is called a person.
