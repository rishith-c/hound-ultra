All images in this folder are AI-generated illustrations, not photographs of real events.

Each image prompt consists of the scene prompt below followed by these shared instructions.

> Photorealistic cinematic illustration for the HOUND student rescue rover website. Natural overcast light, muted earthy palette of graphite, wet concrete, mud brown, mist green. Respectful documentary tone. No text, logos, watermarks, borders, injured or dead people, blood, or identifiable faces.
